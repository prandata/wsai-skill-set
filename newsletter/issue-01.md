## The five from the video.

#### 1. Diagram any repo.

`gitdiagram.com/pallets/click`

Swap github.com for gitdiagram.com. You get an interactive architecture diagram.

![Diagram any repo](assets/shot-gitdiagram.png)

Caption: gitdiagram.com draws the architecture of pallets/click.

#### 2. Turn a repo into one text page.

`gitingest.com/pallets/click`

Swap hub for ingest. You get a summary, the file tree and every file, ready to paste into your AI.

![Turn a repo into one text page](assets/shot-gitingest.png)

Caption: gitingest: (1) the summary with a token estimate, (2) the file tree, (3) Copy all, ready to paste into your AI.

#### 3. See a repo's health.

`ossinsight.io/analyze/pallets/click`

Stars, commits, issues, forks and contributors, charted.

==Its own page warns growth figures undercount since March 2026: trust the totals, not the trend lines.==

![See a repo's health](assets/shot-ossinsight.png)

Caption: OSS Insight: (1) the star total, which is accurate, (2) its own warning that growth charts undercount since March 2026.

#### 4. Add 1s for an editor.

`github1s.com/pallets/click`

Add 1s after github. The repo opens in VS Code, with no sign-in.

![Add 1s for an editor](assets/shot-github1s.png)

Caption: github1s: (1) the file explorer, (2) the editor. No sign-in, no clone.

#### 5. Replay a file's history.

`github.githistory.xyz/pallets/click/blob/main/README.md`

Swap .com for .githistory.xyz on a file link. Every commit plays back like a movie.

![Replay a file's history](assets/shot-githistory.png)

Caption: Git History: (1) every commit to the README, replayed one by one.

## Five more for AI builders.

Not in the video. Each one saves you time on a repo or an AI task.

#### 6. Press . on any repo.

`github.dev/pallets/click`

Pressing the full-stop key on a repo page opens it in VS Code in your browser. Some features need a GitHub sign-in.

#### 7. Make any repo an MCP server.

`gitmcp.io/pallets/click`

Swap github.com for gitmcp.io. You get an MCP address your AI tool can connect to.

#### 8. Find the forks that matter.

`useful-forks.github.io/?repo=pallets/click`

Forks ranked by stars and commits ahead. Sometimes the best version is a fork.

#### 9. Current docs for your AI.

`context7.com/pallets/click`

Up-to-date library docs, with an llms.txt version for AI tools.

#### 10. Explain any shell command.

`explainshell.com/explain?cmd=tar+-xzvf+a.tgz`

Every flag, labelled.
